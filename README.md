## About

This is a legacy project originally built on an Android device using the AIDE app, refactored and cleaned up to meet modern Gradle, AndroidX, and Android Studio standards.

## Features

- Sign In and Sign Up screens with form validation
- Interactive password visibility toggle
- Built with AndroidX and modern Gradle configuration
